# Cars Backend - Админ Панель

Простая веб-админка для управления Cars Backend API.

## 🌐 Доступ

После включения GitHub Pages админка будет доступна по адресу:
```
https://simple-it-pro.github.io/cars-backend/
```

## 📋 Возможности

- **Dashboard** - статистика и информация о приложении
- **Пользователи** - управление пользователями через Swagger API
- **Посты** - управление постами
- **Отзывы** - управление отзывами
- **Чаты** - управление чатами

## 🔗 API

Админка подключается к API: `https://cars-backend-kv4l.vercel.app`

## 🚀 Как включить GitHub Pages

1. Откройте репозиторий на GitHub
2. Settings → Pages
3. Source: выберите `main` branch и папку `/docs`
4. Save
5. Админка будет доступна через несколько минут

## 💡 Использование

Для всех операций требуется авторизация через Swagger API:
1. Откройте Swagger UI
2. Зарегистрируйтесь через POST /auth/register
3. Войдите через POST /auth/login
4. Скопируйте токен
5. Нажмите Authorize в Swagger и вставьте токен
6. Теперь можете делать запросы!
